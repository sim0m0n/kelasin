Link Pantau Pengawas Sekolah (Mode Lihat & Cetak Saja)

Bagikan link ini ke pengawas sekolah. Saat dibuka, data terbaru dari Google Drive kerja Anda otomatis dimuat dalam mode Read-Only (aman, tidak bisa diedit/dihapus).

Panduan Pasang di Akun Google Kerja Anda (Sekali Saja):
  1. Buka script.google.com di browser sambil login menggunakan akun Google kerja Anda, lalu klik Proyek Baru.
  2. Hapus isi bawaan di editor, klik tombol Salin Kode di bawah, lalu tempel (Paste). Anda bisa mengubah TEACHER_PIN sesuai keinginan.
  3. Klik tombol biru Terapkan (Deploy) di pojok kanan atas → pilih Deployment baru → klik ikon gerigi pilih Aplikasi web (Web app).
  4. Pada Jalankan sebagai pilih Saya (akun kerja Anda), dan pada Yang memiliki akses pilih Siapa saja (Anyone), lalu klik Terapkan dan izinkan akses Drive.
  5. Salin URL Aplikasi Web yang muncul (berakhiran /exec), lalu tempel ke Tab 1 di atas.
Kode Google Apps Script (Code.gs) 
const FILE_NAME = 'KELASIN_v4_CLOUD_DATA.json';
const TEACHER_PIN = '123456'; // Samakan dengan PIN Guru di aplikasi KELASIN

function getOrCreateDataFile() {
  const files = DriveApp.getFilesByName(FILE_NAME);
  if (files.hasNext()) return files.next();
  return DriveApp.createFile(FILE_NAME, '{}', MimeType.PLAIN_TEXT);
}

function doGet(e) {
  try {
    const file = getOrCreateDataFile();
    const content = file.getBlob().getDataAsString() || '{}';
    return ContentService
      .createTextOutput(content)
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doPost(e) {
  try {
    const body = JSON.parse(e.postData.contents || '{}');
    if (TEACHER_PIN && body.pin !== TEACHER_PIN) {
      return ContentService
        .createTextOutput(JSON.stringify({ ok: false, error: 'PIN Guru tidak cocok.' }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    const file = getOrCreateDataFile();
    file.setContent(JSON.stringify(body.payload || {}));
    return ContentService
      .createTextOutput(JSON.stringify({ ok: true, updatedAt: new Date().toISOString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ ok: false, error: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
